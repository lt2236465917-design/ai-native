# Pilot checklist (Team example)

- [ ] Select one low-risk customer-facing change.
- [ ] Assign product, engineering and review owners.
- [ ] Commit accepted `intent.md`, `spec.md` and `plan.md`.
- [ ] Run the existing CI checks and record healthy output.
- [ ] Review the diff and neighboring flows; record findings.
- [ ] Do not deploy until the release owner records authorization.
- [ ] Compare cycle time, rework and review findings with the baseline.
- [ ] Decide `continue`, `adjust`, `pause` or `rollback`.
